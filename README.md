# Personal Portfolio Website

A responsive and modern personal portfolio website developed using HTML, CSS, and JavaScript. This website showcases my skills, projects, education, and contact information in a professional and user-friendly manner.

## Features

- Responsive design for mobile and desktop devices
- Attractive homepage with introduction section
- About Me section
- Skills section
- Projects showcase
- Contact section
- Smooth scrolling navigation
- Modern and clean user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
